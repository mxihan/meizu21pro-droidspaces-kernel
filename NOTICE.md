# Public repository notice

This repository is a curated publication of device-specific build artifacts and research. It deliberately excludes phone partition backups, ROM packages, captured module archives, private signing keys, full upstream source trees, and local credential material.

The included `stock-module-signing.pem` and `.x509` files are public certificates. The AOSP AVB test-key provenance file is included for attribution, but the corresponding private key is intentionally omitted.

No claim is made that the candidate is safe for every Meizu 21 Pro ROM. Validate the exact ROM, slot, AVB state, module set, and recovery path before flashing.
